## Локальная модель: ограниченная реальная проверка

Скрипт `scripts/ai/probe-local.py`, команда:

```powershell
python scripts/ai/probe-local.py --env-file H:/projects/SkillMind/.env --output .codex/ai-local-probe.json
```

Ключ читается в памяти и не выводится. Запросы синтетические, только alias qwen-chat. В локальном исходнике `H:/projects/localNexus/litellm/config.yaml` alias направлен в llama.cpp (`http://llm:8001/v1`), указан лимит 4 RPM; платных fallback в этом файле нет. Это проверка локального конфигурационного файла, а не аудит работающего gateway.

| Сценарий | Первый текст | Полный ответ | Результат |
|---|---:|---:|---|
| Русский, уточнение Camry 2018 | 8.469 s | 11.250 s | Уточняет подогрев/датчик дождя; цену не выдумывает |
| Казахский, уточнение Camry 2018 | 3.938 s | 7.734 s | Язык соблюдён, цену не выдумывает; просит VIN/размер вместо важных опций — требуется улучшение сценария |
| Native tool call search_products | нет текстового фрагмента | 9.688 s | Валидный JSON query/year, year=2018, finish_reason=tool_calls |

Эти три проверки не доказывают p95, качество подбора, 10 конкурентных пользователей или работу полного tool-response цикла. Основной маршрут пока gemini_only. Для локальной модели короткий request timeout 8 s недостаточен в наблюдённом случае; общий бюджет turn сохраняется, отдельный локальный timeout согласован с провайдерным исполнителем.
