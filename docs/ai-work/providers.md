# Providers — журнал

- Начато: общий бюджет запроса, безопасные ошибки, Gemini/LiteLLM router, SSE и ограниченный цикл инструментов.
- Контракт reply: messages, BuyerContext, onChunk, cancelled, turnId. BuyerContext не содержит город; фон использует defaultCity и уточнения пользователя, без session.
- БД-тесты выполняет основной агент; здесь только lint и unit без БД.

## Проверка 27 сентября

- `ProviderRouter` передаёт один `AiRequestBudget` локальному провайдеру, Gemini fallback и всем шагам инструментов. Каждый HTTP timeout ограничен остатком бюджета; число попыток общее. При заданном PHP `max_execution_time` бюджет оставляет 5 секунд на обработку ошибки до фатального лимита. Синхронный бюджет по умолчанию — 20 секунд.
- LiteLLM принимает только локальный alias `qwen-chat`, отключает fallback/retry в payload и не переключает провайдера после уже выданного текста. Исправлен порядок истории: assistant с `tool_calls` всегда предшествует `tool`-ответу; ответ без исходного вызова отвергается.
- SSE decoder проверяет завершающую причину, не отдаёт мысли Gemini, собирает фрагменты аргументов инструмента отдельно от текста и ограничивает их размер. Неверные типы в потоковых фрагментах превращаются в контролируемую ошибку.
- Разрешённый Gemini model ID `gemini-3.1-flash-lite` сверён с [официальной страницей модели](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite) и [таблицей цен](https://ai.google.dev/gemini-api/docs/pricing): для Standard text API указан Free Tier. Модель сама по себе не гарантирует отсутствие списаний; ключ должен принадлежать проекту без платного биллинга. CRM может выбирать модели только из пересечения конфигурации и проверенного списка.
- Unit-проверка `RequestBudgetAndStreamTest`: 12 тестов, 26 assertions, успешно. Feature transport suite основан на `Tests\TestCase`, который всегда подключается к PostgreSQL через `TestDatabaseGuard`; отдельным параллельным запуском его не выполняли.

Основной агент ранее выполнил `scripts/ai/probe-provider.php` против локального `qwen-chat`: PHP SSE отдал первый текст через 6.575 с, завершился через 9.209 с, 30 фрагментов, текст корректно различал ADAS-камеру; native tool call завершился через 9.244 с с валидными `query` и `year`. Это одна ограниченная реальная проба, не оценка p95 или качества всего диалога.
