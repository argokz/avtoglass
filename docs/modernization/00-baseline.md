Проблемы подготовки и решения:

- PHP с 128 MB исчерпал память. Runner и PHPUnit переведены на 512 MB; полный повторный запуск успешен.
- На мобильной карточке два действия «В корзину»; локатор уточнён до основного блока покупки, после добавления тест ожидает подтверждение ответа сервера.
- PowerShell/npm поглощал часть аргументов выборочного запуска Playwright; README использует прямой Node runner.
- Vite сообщает об отсутствующем необязательном fontaine для оптимизированных fallback-шрифтов. Сборка успешна, пакет не добавлялся автоматически.

Три синтетических предложения; пять последовательных обработок после одного прогрева на маршрут. Время — Laravel Kernel в одном PHP-процессе; SQL учитывается через DB::listen.

| Маршрут | Медиана обработки, ms | SQL |
|---|---:|---:|
| / — в исходной версии чат | 49,32 | 23 |
| /catalog | 88,61 | 41 |
| /search?q=Camry | 140,21 | 48–49 |
| /tovar/preview-camry-70 | 161,29 | 62 |
| /chat | 53,65 | 23 |

Цифры пригодны для поиска лишних запросов. Пять измерений и три предложения не подтверждают p95/p99, нагрузку на 50 000 предложений / 100 покупателей, Web Vitals или production PHP-FPM. Нет измерений сети, реального Gemini и Redis.
