# Витрина и новый логотип

Дата: 8 октября 2026 года.

## Реализовано

- Установлены оба предоставленных PNG без изменения рисунка: прозрачный глянцевый вариант в `public/images/logo.png`, вариант на белом фоне в `public/images/logo-light.png`. SHA-256 установленных файлов совпадает с исходниками.
- Общий компонент логотипа выбирает оформление для светлой/тёмной темы и подвала. Размеры изображений указаны явно; исходные пропорции сохранены. CSS убирает только внешние пустые поля. Светлая подложка обеспечивает читаемость тёмных букв в тёмной теме. Параметр версии URL обновляет ранее закешированный логотип.
- Главный экран объединён с подбором автомобиля. Красный разделитель связывает иллюстрацию стекла с формой; быстрые ссылки ведут в каталог с существующим фильтром типа стекла.
- Сокращено описание на главной, выделены подбор по автомобилю и поиск по артикулу. Мобильный переход к форме учитывает высоту закреплённой шапки.
- Шапка разделяет поиск/основную навигацию и выбор режима/контакты. Текущий каталог и текущий пункт нижней мобильной навигации обозначены визуально и через `aria-current`.
- Палитра витрины согласована с красным и графитом логотипа. Тёмная тема получила более читаемые поверхности и текст; у основных кнопок убрано свечение.
- В карточке товара бейджи поставщика переносятся на узких экранах. Нижняя мобильная панель содержит цену и одно действие «Оформить». Покупка в один клик доступна в основном блоке карточки.
- Колонки формы оформления и `fieldset` могут сжиматься до ширины экрана. Нативный выбор времени больше не расширяет корзину на 320–390 px.
- Артефакты Playwright исключены из Git через `.gitignore`.

## Проверенная среда и команды

Изолированный preview: `http://127.0.0.1:18015`, подтверждён `/preview/health` с маркером `avtoglass-isolated-v1`. Порт 8015 занят другим приложением. Используется существующая preview-БД; рабочие данные и `.env` не изменены.

```powershell
& C:/php/php.exe -d memory_limit=512M artisan serve --env=preview --host=127.0.0.1 --port=18015 --no-reload
npm run build
./scripts/test.ps1 tests/Feature/CatalogTest.php tests/Feature/StorefrontModeTest.php tests/Feature/SubpathTest.php
$env:PREVIEW_URL='http://127.0.0.1:18015'
node node_modules/@playwright/test/cli.js test tests/Browser/redesign.spec.js tests/Browser/storefront-2026.spec.js
git diff --check
```

- Финальная сборка Vite успешна. Существующее предупреждение об optional `fontaine` не блокирует сборку.
- Целевой PHP-набор: **40 тестов / 133 assertions, 0 failures**, через защищённый runner и отдельную тестовую БД. Повтор после исправления карточки также успешен.
- Ручная проверка Chromium: обе версии логотипа загружаются; тема переключается; главная, карточка товара и корзина на 320 px не имеют горизонтального переполнения. В мобильной панели товара одна кнопка. На 390 px переход к подбору размещает форму ниже шапки: начало формы 256 px, низ шапки 226 px.
- Первые браузерные прогоны выявили переполнение бейджа производителя на 320 px, две кнопки в мобильной панели вместо одной и минимальную ширину формы корзины, задаваемую нативным выбором времени. Все три причины исправлены.
- Итоговый браузерный прогон после исправлений: **28 passed / 10 skipped / 0 failed**, 4,7 минуты. Десять пропусков предусмотрены существующим тестом: матрица ширин выполняется один раз в desktop-проекте. Проверены 320, 360, 390, 768 и 1365 px в светлой и тёмной темах на главной, поиске, товаре и корзине; также выбор предложения, цена с установкой, неизвестная цена, количество, подсказки поиска, один клик и мобильная навигация. Ошибок JavaScript в матрице нет.
- `git diff --check` успешен; изменённые текстовые файлы сохранены в UTF-8 с LF.
